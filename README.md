# 💻 Estudos em C

Este repositório foi criado para organizar meus **estudos e práticas na linguagem C**, reunindo exercícios desenvolvidos durante as aulas da faculdade e atividades realizadas para reforçar meus conhecimentos em programação.

## 🎯 Objetivo

O objetivo deste repositório é acompanhar minha evolução na linguagem C, praticando desde os fundamentos até conceitos mais avançados ao longo dos estudos.

Os códigos presentes aqui são utilizados principalmente para:

* Praticar lógica de programação;
* Revisar conteúdos vistos em aula;
* Aprender a sintaxe da linguagem C;
* Resolver exercícios e desafios;
* Desenvolver pequenos programas;
* Registrar minha evolução durante a graduação.

## 🎓 Faculdade

Parte dos exercícios deste repositório está relacionada aos conteúdos estudados durante minha graduação em **Desenvolvimento de Software Multiplataforma (DSM)**.

O repositório será atualizado conforme o avanço das aulas, servindo como registro do meu aprendizado e evolução na linguagem C.
